Predicciones Deportivas Pro

Análisis avanzado y pronósticos de partidos mediante Inteligencia Artificial y Redes Neuronales (TensorFlow).

El Proyecto

Esta aplicación utiliza el ciclo de vida de Machine Learning (CRISP-ML) para procesar datos históricos, identificar patrones y predecir resultados deportivos con alta precisión.


Nuestra arquitectura se basa en una Red Neuronal Densa (Feed Forward) construida con Keras, optimizada para clasificación multiclase (Local, Empate, Visitante).

Variables del Modelo

  • Ranking Local: Posición actual del equipo anfitrión.
  • Ranking Visitante: Posición actual del equipo visitante.
  • Goles Promedio (Últimos 5): Tendencia ofensiva reciente.
  • Eficiencia de Tiro: Ratio de goles por tiros a puerta.

Arquitectura Neuronal

  • Capa de Entrada: 4 neuronas (features estandarizados).
  • Capas Ocultas: 16 y 8 neuronas (Activación ReLU).
  • Capa de Salida: 3 neuronas (Softmax) para probabilidades Win/Draw/Loss.
  • Optimizador: Adam (Pérdida: Sparse Categorical Crossentropy).
Precisión Esperada
~82%
